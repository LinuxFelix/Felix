# Aqua-inspired native theme

The theme uses DejaVu Sans, white content areas, dark blue-gray text, pale blue
window surfaces and a restrained reflection on buttons. It disables FLTK's
plastic scheme so the gray tiled/striped background from the preceding build
does not return. `aqua.h` supplies native box drawing; no compositor is required.

Applications keeps search at the top, results in the center, and package actions
below. Install is the primary blue action. Inputs and actions disable together
during package work. The existing dependency preview and install confirmation
are preserved. The window cannot shrink below the designed layout.

Flwm's matching paint lives in `userland/flwm/Glass.H`. The title shadow is now
white below dark lettering. The clock uses the same surface and darker digits.
Wallpaper and dock artwork are regenerated by `tools/make-theme.py`.

# Glass and dither refinement

Controls now use a split reflection, pale blue surfaces, white content areas and dark text. Flwm paints matching reflective active frames with coral close controls. These are opaque glass-style effects; there is no compositor blur. Gradients in controls use integer arithmetic and horizontal spans.

Settings → Desktop offers Ocean glass, Midnight glass and Silver mist wallpapers. Select a design, then Save and apply. The designs change the wallpaper; the shared controls retain their readable light palette. The generator pre-renders a curved reflection and 4×4 ordered RGB565 dithering, so the desktop does no animation work. The wbar plate has a translucent highlight.

Notepad adds Ctrl+F search with wraparound, a word-wrap toggle, and uses the current user's Documents folder. Clicking the desktop clock opens Settings; repeated clicks do not spawn multiple Settings children, and completed children are reaped.

Flwm submits geometry changes with XFlush instead of a synchronous server round trip. TinyX's packed shadow updater copies contiguous framebuffer-bank spans with memcpy and rejects zero-length banks. These are specific implementation improvements, not a claim of measured frame-rate gains. `tools/test-shadow.py` tests the actual updater against banked, unaligned and multi-rectangle damage plus empty-bank handling.
